# Proposed fixes

Patch write-ups for the pre-2026-08 bugs, written before the fixes landed.

Every bug they describe is now resolved, and each file carries a
"superseded" note pointing at the bug file. They are kept because the
reasoning is sometimes worth reading — and because in several cases what was
actually done differs from what was proposed, which is itself worth seeing.

The 2026-08-15 audit batch (bugs 07-48) described its fixes inline in the bug
files rather than here; that is the pattern to follow for new bugs.
